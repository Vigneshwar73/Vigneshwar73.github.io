IOT-based remote water quality monitoring system

  • Keywords: Total Dissolved Solids (TDS), real-time monitoring, RTOS scheduling, MQTT protocol
  • Tech Stack: Arduino, ESP8266, XBee (RF), MQTT (IoT messaging protocol), FreeRTOS, C/C++

  • Designed and implemented a real-time water quality monitoring system using sensors to track Total Dissolved Solids (TDS), temperature, and flow rate.
  • Integrated Arduino microcontrollers with XBee and ESP8266 modules for wireless data transmission via MQTT protocol to a secure web dashboard.
  • Developed a web-based interface for remote monitoring and alerting, accessible only to authorized personnel for enhanced security.
  • Utilized FreeRTOS to enable multitasking and improve system reliability by prioritizing sensor data processing tasks.
  • Implemented fail-safe mechanisms to automatically shut down the water outlet and trigger alerts in case of purification unit malfunction
