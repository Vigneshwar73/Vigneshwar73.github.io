Virtual advertising in Sports

  • Keywords: Virtual advertising, Image warping, Camera calibration, RANSAC, Homography, real-time video processing
  • Tech Stack: MATLAB, Image processing Toolbox, Computer Vision Toolbox, RANSAC, morphological operations, homography transformation, Skeletonization, thresholding

  • Developed a virtual advertising framework for tennis match videos using computer vision techniques to dynamically overlay region-specific ads on the court.
  • Implemented image pre-processing and line detection using morphological operations and the RANSAC algorithm to extract court boundaries and intersection points.
  • Performed camera calibration by estimating intrinsic and extrinsic parameters to map 2D image coordinates to 3D world coordinates for accurate ad placement.
  • Applied homography and image warping to seamlessly integrate virtual ads into the video frames, maintaining perspective and realism.
  • Executed the entire pipeline in MATLAB, leveraging the Image Processing and Computer Vision toolboxes for real-time frame-by-frame processing.
